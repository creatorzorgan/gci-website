## 2. How the 3D is wired

One transparent canvas behind the page (`components/canvas/Scene.tsx`); each piece renders
into a page element's box with drei's `View`: `#stage-world`, `#stage-city`,
`#stage-valves`, `#stage-colonnade`, `#stage-stamp`. Choreography for the shared world is in
`lib/directive.ts`. Everything is generated in code (no models, no texture downloads).
